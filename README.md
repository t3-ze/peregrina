# PEREGRINA

경계 너머의 세계 '아발론'을 소개하는 정적 웹사이트예요. 빌드 과정 없이 `index.html`을 그대로 올리면 돼요(GitHub Pages 등). ES 모듈을 쓰기 때문에 로컬에서는 간단한 웹 서버로 열어야 해요.

```bash
python tools/serve.py 8766
```

## 화면 흐름
- 여는 화면: 밤하늘에 도착한 봉인된 편지. 봉인을 누르면 편지가 펼쳐지고 별빛으로 흩어지며 세계로 들어가요. 이때 배경 음악이 시작돼요.
- 세계 지도: 별똥별이 떨어지는 밤하늘과 도는 플라니스피어 위의 아발론 전도. 대륙에 손을 올리면 그 대륙만 떠오르고, 누르면 그 대륙을 당겨 보여 주며 소개 패널·기관 그림·앰비언트 소리가 나와요.
- 기관 도면: 건물을 세로로 자른 단면도. 인물 표식을 누르면 프로필이 떠요.
- 아발론 연대기: 지도 오른쪽 위 붉은 책갈피를 누르면 책장을 넘기듯 책장 화면으로 가요(돌아올 때는 왼쪽 위 책갈피). 빛나는 책등을 누르면 책이 펼쳐지고, '인물 명부'에서 모든 인물 카드를 볼 수 있어요.
- 스포일러: 유리탑과 사과나무 숲, 숨겨진 인물, `[비밀]` 내용은 흐리게 가려 두고 확인을 받은 뒤 보여 줘요.
- 소리: 왼쪽 아래 음표 버튼으로 배경 음악과 앰비언트를 함께 켜고 꺼요. 누를 수 있는 것을 누르면 클릭음이 나요.

## 파일
- `index.html`, `css/style.css`: 뼈대와 스타일 (맨 위 주석에 팔레트·선·움직임 규칙)
- `js/main.js`: 여는 화면, 지도·대륙 강조, 패널, 도면·인물 창, 책장과 책, 화면 넘김
- `js/map.js`: 대륙 윤곽, 지형, 바다 장식, 지도 표식 배치(`POS`)
- `js/glyphs.js`: 지도 위 기관 그림
- `js/sections.js`: 기관 단면도의 층 구성(`SEC`)과 가구·계단·지붕 그림
- `js/frames.js`: 인물 프로필 프레임 11종
- `js/planisphere.js`: 배경의 성좌 원반
- `js/emblems.js`: 연대기 책 문양
- `js/books.js`: 아발론 연대기 책 내용
- `js/bios.js`: 인물 소개문 (프로필을 줄글로 줄인 것)
- `js/bgm.js`: 배경 음악 목록(`TRACKS`)과 대륙별 앰비언트(`AMBIENT`) — 유튜브 영상 ID
- `js/sfx.js`, `assets/sfx/click.mp3`: 클릭음
- `js/cursor.js`: 마법봉 포인터와 별가루 효과
- `js/data.js`: 로어북에서 자동 생성한 데이터 (직접 고치지 말 것)
- `js/main.js`의 `SITE_FIELDS`: 숨겨진 인물이 사는 장소의 설명 덮어쓰기

## 데이터 다시 만들기
티팟 저장본 JSON(`snapshot` 객체)에서 로어북을 읽어 `js/data.js`를 만들어요. `[비밀]` 줄은 spoiler로 표시돼요.

```bash
node tools/build-data.mjs <snapshot.json>
```

## 초상화
원본은 `portraits/`(저장소 제외)에 두고, 웹용 사본을 `assets/portraits/`에 같은 경로로 둬요.
